This page talks to ecom-demo-gateway, a small standalone service exposing the same schema as this repo's graphql-gateway (getProducts, createProduct, …), backed by a JSON file instead of the full MongoDB + Kafka + 3-service stack in the main repo — that stack needs infra this static page can't run. It's on a free tier, so data resets periodically and the first request after idling can take ~30s to wake up. Source: ecom-demo-gateway repo.
